# Week 1: Data Landscape and Requirement Assessment

A report for a simulated integrated farm-to-market agribusiness, **AgriSense Farms Pvt Ltd**, operating in Gujarat and Madhya Pradesh (wheat, rice and soybean).

## What the report covers

- Executive summary
- Data landscape framework: climate, soil and crop, market, logistics and storage, finance and input costs
- Data requirement analysis with public sources (Agmarknet, NASA POWER, IMD, Soil Health Card, FAOSTAT and others) and collection methods
- Data integration approach (location, crop, time and unit keys; layered architecture)
- Data quality and integration challenges with mitigations
- Expected impact on decision-making
- Conclusion and next steps for further research
